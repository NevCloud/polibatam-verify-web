Introduction

REST API v1 untuk aplikasi mobile Admin SILAU & Admin Keuangan (P06, FR-60). Tidak ada endpoint peserta maupun keputusan massal.

Base URL: http://127.0.0.1:8000 
Format respons: `{success, message, data, meta}`; galat: `{success: false, message, code, errors}`. Waktu ISO 8601 UTC, uang integer Rupiah.
Login dua tahap: `POST /auth/login` → `challenge_token` → `POST /auth/two-factor` → token Bearer 12 jam per perangkat.
Setiap keputusan verifikasi membawa `versi`; bila data sudah diputuskan admin lain → 409 `SUDAH_DIVERIFIKASI`.

Authenticating requests

To authenticate requests, include an Authorization header with the value "Bearer {TOKEN}".

All authenticated endpoints are marked with a requires authentication badge in the documentation below.

Token diperoleh dari POST /auth/two-factor setelah login; berlaku 12 jam.

Autentikasi

Login dua tahap (FR-60, BR-59, NFR-47): password → challenge_token → kode TOTP → token Bearer 12 jam per perangkat.

Login (tahap 1)

Selalu mengembalikan challenge_token (2FA wajib untuk admin, K-33). Hanya Admin SILAU & Admin Keuangan; role lain 403.

Example request:
curl --request POST \
    "http://127.0.0.1:8000/api/v1/auth/login" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"email\": \"silau@polibatam-verify.test\",
    \"password\": \"|]|{+-\",
    \"nama_perangkat\": \"Pixel 8 Bayu\"
}"

const url = new URL(
    "http://127.0.0.1:8000/api/v1/auth/login"
);

const headers = {
    "Content-Type": "application/json",
    "Accept": "application/json",
};

let body = {
    "email": "silau@polibatam-verify.test",
    "password": "|]|{+-",
    "nama_perangkat": "Pixel 8 Bayu"
};

fetch(url, {
    method: "POST",
    headers,
    body: JSON.stringify(body),
}).then(response => response.json());

    --header "Authorization: Bearer {TOKEN}" \
    --header "Content-Type: application/json" \
    --header "Accept: application/json" \
    --data "{
    \"versi\": \"2026-11-26 03:00:00.000000\"
}"

const url = new URL(
    "http://127.0.0.1:8000/api/v1/verifikasi-pembayaran/TG-UJI-0001/lunas"

    "Authorization": "Bearer {TOKEN}",
    "Content-Type": "application/json",
    "Accept": "application/json",
