## Cek basis data (sebagai pv_dba)

```sql
-- Login, logout, gagal, aktivasi, buat/ubah akun tercatat (BR-58, A-78)
SELECT id, user_id, role, aksi, hasil, alasan, kanal, created_at FROM audit_logs ORDER BY id DESC LIMIT 20;
-- Persetujuan privasi tercatat bersama waktunya (NFR-11)
SELECT email, privacy_consented_at, email_verified_at FROM users ORDER BY id DESC LIMIT 5;
-- TOTP tersimpan terenkripsi (BR-59)
SELECT email, LEFT(two_factor_secret, 20) AS rahasia_terenkripsi, two_factor_confirmed_at FROM users WHERE two_factor_secret IS NOT NULL;
```
