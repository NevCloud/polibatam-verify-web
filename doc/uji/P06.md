### Mendapatkan token (PowerShell)

Ganti email/password sesuai akun Anda; `code` = 6 digit dari aplikasi autentikator saat itu.

```powershell
$api = 'http://127.0.0.1:8000/api/v1'
$h = @{ Accept = 'application/json' }
$t1 = Invoke-RestMethod "$api/auth/login" -Method POST -Headers $h -ContentType 'application/json' `
  -Body (@{ email = 'silau@polibatam-verify.test'; password = 'Fahad123'; nama_perangkat = 'Laptop Uji' } | ConvertTo-Json)
$t1.data.challenge_token
$t2 = Invoke-RestMethod "$api/auth/two-factor" -Method POST -Headers $h -ContentType 'application/json' `
  -Body (@{ challenge_token = $t1.data.challenge_token; code = '123456' } | ConvertTo-Json)
$tokenSilau = $t2.data.token; $t2.data.kedaluwarsa_pada
Invoke-RestMethod "$api/me" -Headers ($h + @{ Authorization = "Bearer $tokenSilau" })
```

Ulangi untuk `keuangan@polibatam-verify.test` → `$tokenKeuangan`.
