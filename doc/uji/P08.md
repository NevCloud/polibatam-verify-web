## SQL penyiapan (sebagai `pv_dba`)

**Tutup sementara (TC-P08-08)** — catat dulu `id` periode yang dibuka:

```sql
SELECT id, nama, status, tanggal_mulai, tanggal_selesai FROM periode_pendaftarans;
UPDATE periode_pendaftarans SET status = 'dijadwalkan' WHERE id = <id_periode_dibuka>;
```

Pemulihan:

```sql
UPDATE periode_pendaftarans SET status = 'dibuka' WHERE id = <id_periode_dibuka>;
```
