## SQL penyiapan (sebagai `pv_dba`)

**Batal 7 hari (TC-P04-15)** — pakai pendaftaran Masuk Kuota hasil TC-P04-12 (ganti nomornya), tanpa tagihan:

```sql
UPDATE pendaftarans SET waktu_masuk_kuota = UTC_TIMESTAMP() - INTERVAL 8 DAY
WHERE nomor_pendaftaran = 'PV-2026-0000xx' AND status = 'masuk_kuota';
```

**Tutup periode (TC-P04-16)**:

```sql
UPDATE periode_pendaftarans SET tanggal_selesai = UTC_TIMESTAMP() - INTERVAL 1 MINUTE WHERE id = 1;
```

Pemulihan setelah TC-P04-16 (periode dibuka lagi, Draf peserta3 kembali):

```sql
UPDATE periode_pendaftarans SET status = 'dibuka', ditutup_pada = NULL, tanggal_selesai = '2027-01-31 16:59:59' WHERE id = 1;
UPDATE pendaftarans SET status = 'draf', alasan_batal = NULL WHERE id = 43;
```
