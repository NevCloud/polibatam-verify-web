## Nomor bersamaan (TC-P03-25)

Dua proses PHP terpisah ke DB lokal (dijalankan Claude, 26-11-2026, keduanya rollback sehingga penghitung tetap 46):

```
17:18:02 A dapat PV-2026-000047          ← A mengunci baris penghitung (FOR UPDATE), menahan 8 detik
17:18:07 B mulai
17:18:10 A rollback
17:18:10 B dapat PV-2026-000047 setelah menunggu 3.2s   ← B tertahan sampai A selesai
```

Ulangi sendiri di dua terminal (`php artisan tinker`):

```php
// Terminal A
DB::beginTransaction(); app(App\Services\NomorPendaftaranGenerator::class)->berikutnya();   // jangan commit dulu
// Terminal B (tertahan sampai A selesai)
DB::beginTransaction(); app(App\Services\NomorPendaftaranGenerator::class)->berikutnya();
// Terminal A
DB::commit();      // B langsung mendapat nomor berikutnya (A +1). Akhiri B dengan DB::rollBack();
```

`DB::commit()` di terminal A memakai satu nomor; gunakan `DB::rollBack()` bila tidak ingin melompati nomor.

## Cek basis data (sebagai pv_dba)

```sql
-- NIK terenkripsi + nik_hash (BR-62), nomor & status (BR-68)
SELECT nomor_pendaftaran, status, LEFT(nik_terenkripsi, 20) AS nik_terenkripsi, LEFT(nik_hash, 16) AS nik_hash, waktu_pengajuan
FROM pendaftarans ORDER BY id DESC LIMIT 5;
-- Riwayat versi: nama acak di disk privat (NFR-07), nama asli hanya metadata
SELECT d.pendaftaran_id, d.jenis, d.status, v.id AS versi, v.path, v.nama_asli, v.mime, v.ukuran
FROM dokumen_versis v JOIN dokumens d ON d.id = v.dokumen_id ORDER BY v.id DESC LIMIT 10;
-- Audit: buat_draf_pendaftaran, ajukan_formulir, unggah_ulang_dokumen, ajukan_ulang_berkas
SELECT id, user_id, aksi, entitas_type, entitas_id, created_at FROM audit_logs ORDER BY id DESC LIMIT 10;
```
